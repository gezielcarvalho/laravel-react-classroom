# Project charter

## Purpose

Laravel React Classroom is a full-stack educational/portfolio application and
foundation for a possible education SaaS. Its current implementation provides
student-record CRUD through a Laravel API and React frontend, with Docker-based
local development.

## Stakeholders and users

| Group | Need / responsibility |
| --- | --- |
| Portfolio reviewer | Understand full-stack architecture and delivery practices quickly |
| Developer / contributor | Run, test, and extend the application safely |
| Future product owner | Evaluate the SaaS direction without treating it as committed scope |

## Success criteria

- [ ] The local application and its boundaries are understandable from the README and this folder.
- [ ] Detailed project goals and scope are traceable to `docs/project/`.
- [ ] Portfolio claims distinguish current CRUD capability from future SaaS ideas.

## Constraints

- This repository is a demonstration/foundation, not an approved production service.
- Existing runbooks and plans require validation before operational use.
- Infrastructure, credentials, and deployment are outside this documentation baseline.
