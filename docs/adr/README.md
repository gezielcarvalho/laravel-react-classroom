# Architecture decision records

Use an ADR for a decision with lasting architecture, security, operational, or
cost implications. Keep accepted records short and immutable.

```text
# ADR-001: <decision title>

## Status
Proposed | Accepted | Superseded

## Context
What requires a decision?

## Decision
What was chosen?

## Consequences
What becomes easier, harder, riskier, or deferred?
```
