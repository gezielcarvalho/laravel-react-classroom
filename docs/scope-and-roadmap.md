# Scope and roadmap

## Current scope

- Laravel REST API and React TypeScript frontend.
- Student-record CRUD workflow.
- MySQL, phpMyAdmin, MailHog, and Docker Compose local development support.
- Documentation and planning for a potential education SaaS evolution.

## Out of scope

- Claiming a production-ready SaaS or a current hosted environment.
- Enabling Jenkins, QA, production deployment, or external integrations as part of documentation work.
- Treating future product plans as implemented functionality.
