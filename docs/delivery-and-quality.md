# Delivery and quality

## Delivery workflow

1. Create a scoped GitHub Issue with objective, exclusions, acceptance criteria, validation, and human gates.
2. Add approved work to **Personal Portfolio & Engineering Labs**.
3. Implement through a pull request with relevant evidence.
4. Obtain review and human acceptance before release or deployment decisions.

## Definition of Done

- [ ] Acceptance criteria are met.
- [ ] Applicable API, frontend, and/or integration validation is recorded.
- [ ] Current documentation is updated when behavior, architecture, or operations change.
- [ ] Rollback is known, or `Not required` is explained.
- [ ] Required human review and acceptance have occurred.
